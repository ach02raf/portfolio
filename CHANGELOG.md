# Changelog

All notable changes to this portfolio are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [4.0.0] - 2026-11-19

### Added
- Static, multilingual portfolio rebuild (FR/EN/DE) with localized routes, content dictionaries, and browser-language-aware first-open locale handling with persistence.
- Project case studies and writing sections with dedicated pages and localized content (19 projects, 20 posts per locale).
- Real, site-accurate project covers/media for key projects (RAG Document Assistant, CommunicFlow v2, Kickoff, CommunicFlow v1) and improved project media/label/link presentation.
- SEO foundations: metadata, Open Graph/Twitter cards, structured data, sitemap/robots generation, and accessibility-minded UI updates.
- Professional release and repository configuration (changelog, release workflow/config, contribution and issue templates).

### Changed
- Repositioned portfolio messaging for full-time opportunities across **Web, Mobile, DevOps, and AI** (not freelance-only or AI-only).
- Refreshed UI/UX: navigation and mobile burger behavior, project/work presentation, media handling (including `.webm`/`.svg`), and polished responsive layout.
- CI/CD updated for static export and GitHub Pages deployment.

### Removed
- Backend/API, contact/review form handling, and related server-side/credentialed integrations in favor of a pure static site with direct contact links (email/phone/location).

### Fixed
- Mobile/tablet navigation reliability (visibility, scroll-lock/width behavior) and various project/content/link correctness issues.
