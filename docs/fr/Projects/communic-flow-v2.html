Communic Flow — Version 2

Communic Flow v2 est la version repensée et modernisée de la plateforme organisationnelle multiniveau, désormais reconstruite avec une architecture en microservices. Le module de messagerie est entièrement séparé en tant que service indépendant, alimenté par GraphQL et Redis pour la communication interne. Le système d’authentification a été renforcé avec des cookies HTTP-Only pour les tokens, une nouvelle connexion via Google OAuth 2.0, Cloudflare Turnstile pour bloquer le spam, ainsi qu’un système complet de double authentification (2FA). La création d’entreprise est optimisée grâce à la validation automatique VIES des sociétés européennes et à l’autocomplétion d’adresse via le code postal. La sécurité du backend a été fortement améliorée, la messagerie instantanée optimisée, et les fonctionnalités d’appel vocal et vidéo sont déjà en cours d’intégration.

Fonctionnalités principales

✔ Architecture microservices avec service de messagerie isolé

✔ Moteur de messagerie basé sur GraphQL pour des requêtes optimisées

✔ Redis utilisé pour la communication inter-services et le streaming d’événements

✔ Authentification sécurisée via cookies HTTP-Only pour les tokens

✔ Nouvelle connexion Google OAuth 2.0

✔ Protection anti-spam via Cloudflare Turnstile

✔ Système complet de double authentification (2FA)

✔ Création d’entreprise optimisée avec validation automatique VIES (UE)

✔ Autocomplétion d’adresse basée sur le code postal

✔ Sécurité backend renforcée avec meilleures validations et protection des tokens

✔ Messagerie instantanée optimisée en performance et scalabilité

✔ Fonctionnalités d’appel vocal et vidéo en cours de développement

✔ Amélioration future des interactions entre utilisateurs

✔ Nouveau mode sombre (Dark Mode)
