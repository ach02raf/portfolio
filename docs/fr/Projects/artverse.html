ARTVERSE

INFOS PROJET
Création d'une application web responsive pour l'art numérique : ARTIVESE

Notre projet consiste à créer une plateforme dédiée à l'art numérique, offrant aux artistes un espace pour exposer leurs créations. Cette initiative s'inscrit dans la tendance croissante des plateformes en ligne qui facilitent la communication, le partage d'informations et la collaboration dans le domaine artistique, tout en ouvrant de nouvelles perspectives pour la promotion culturelle.
