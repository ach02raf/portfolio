Communic Flow — Version 2

Communic Flow v2 represents the redesigned and upgraded version of the multi-level organizational platform, now rebuilt with a modern microservices architecture. Messaging is fully isolated as an independent service powered by GraphQL and Redis for inter-service communication. The authentication system has been enhanced with secure HTTP-Only cookies, Google OAuth 2.0, Cloudflare Turnstile to block spam, and a complete two-factor authentication flow. Company creation is optimized with automated VIES validation for EU companies and ZIP-based address autofill. Backend security has been significantly reinforced, and real-time messaging performance has been improved to support future features such as voice and video calling.

Main Features

✔ Microservices-based architecture with isolated real-time messaging service

✔ GraphQL-powered messaging engine for optimized queries and subscriptions

✔ Redis used for inter-service communication and event streaming

✔ Secure authentication using HTTP-Only cookies for JWT tokens

✔ New Google OAuth 2.0 login flow

✔ Cloudflare Turnstile anti-spam protection

✔ Full two-factor authentication (2FA) system

✔ Improved company creation process with VIES automatic EU validation

✔ ZIP code based automatic address detection

✔ Enhanced backend security with stricter validations and improved token handling

✔ Optimized instant messaging with better performance and scalability

✔ Voice call and video call features under development

✔ Upcoming improvements for user-interaction linkage across organizations

✔ New UI experience including Dark Mode
