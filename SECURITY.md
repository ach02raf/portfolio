# Security Policy

## Supported Versions / Branches

This is a personal portfolio project. Security fixes are provided for the active development branch and the latest release tag.

| Track          | Supported |
| -------------- | --------- |
| `main`         | ✅        |
| Latest release | ✅        |

If you are running a forked deployment, please rebase regularly against `main`.

## Reporting a Vulnerability

Please email security reports to `ach02raf@gmail.com` and optionally open a private security advisory on GitHub (Security → Advisories) if available. Include:

- Description of the issue and potential impact
- A minimal reproduction (URLs, steps, payloads)
- Affected commit/tag or deployment URL
- Logs or screenshots if helpful

Do not open public issues for unpatched vulnerabilities.

## Response Expectations

- Acknowledgement: within 5 business days
- Triage and next steps: within 10 business days
- Fix/mitigation: prioritized based on severity and impact

If you do not receive acknowledgement within the window above, please resend your report.

## Scope

- This repository’s code and deployed portfolio site (if provided by the author)
- Dependencies are in scope only where the portfolio’s usage introduces the issue

Out of scope examples: third-party services, analytics provider outages, social links owned by third parties.

## Safe Harbor

We will not initiate legal action for good-faith research that respects the following:

- Avoid privacy violations and data destruction
- Do not impact availability for other users
- Do not attempt social engineering or phishing
- Provide adequate detail to reproduce the issue
